                  OVERVIEW

                  돈은 모아야 하는데
                  절약은 왜 이렇게 재미없을까?

                  작심삼일 가계부,
                  광고만 보게 되는 앱테크,
                  결국 오래 남는 건 없었습니다.

                  DESK RESEARCH

                  절약은 왜
                  늘 작심삼일로 끝날까?

                  고물가 시대와 소비 중심 문화 속에서 MZ세대는
                  ‘돈을 아껴야 한다’는 압박을 느끼고 있습니다.

                  하지만 기존 절약 서비스들은 기록과 통제 중심의 UX가 많고,
                  지속적으로 사용하게 만드는 동기는 부족합니다.

                  지속 사용 경험 중심 설계 필요

                  PROJECT GOAL

                  자린고비의 목표를 설정했어요

                  자린고비는 단순한 가계부 앱이 아니라
                  절약 행동을 게임처럼 지속할 수 있도록 설계한 챌린지형 캐릭터 성장 서비스입니다.

                  Solution 1

                  생활형 절약 챌린지

                  배달 대신 집밥, 카페 대신 텀블러처럼
                  일상 속에서 실천 가능한 절약 미션 제공

                  Solution 2

                  행동 기반 성장 경험

                  절약 행동이 쌓일수록 포인트로 보상받고,
                  캐릭터가 성장하는 구조 설계

                  Solution 3

                  커뮤니티 기반 지속성

                  절약 정보 공유, 인증 챌린지,
                  유저 간 반응 시스템을 통해
                  꾸준히 참여하게되는 구조 설계

                  GOAL

                  절약 행동이 즐거운 습관이 되는
                  생활형 절약 게이미피케이션 서비스

                  BEAUTY CONTENT LAB / 03 EXPERIMENT

                  운영하면서 확인한
                  콘텐츠 실험 포인트

                  하나의 카드뉴스를 플랫폼별 소비 방식에 맞게 변환하기

                  같은 원본 콘텐츠를 여러 플랫폼에 운영하며
                  효과적인 방식과 개선점을 실험하고 운영 전략을 조정했습니다.

                  KEY INSIGHT

                  단순히 여러 채널에 업로드하는 것이 아니라,
                  각 플랫폼에서 어떤 방식이 더 적합한지 비교하며 운영 방식을 조정했습니다.

                  TEST 01

                  카드뉴스는
                  숏폼으로 재활용 가능한가?

                  인스타그램과 유튜브 쇼츠는 카드뉴스 이미지를
                  이어붙여 짧은 영상 형태로 재가공했습니다.

                  결론

                  촬영 없이도 콘텐츠 확장이
                  가능했지만, 영상 전용 콘텐츠보다
                  몰입감은 조정이 필요했습니다.

                  TEST 02

                  플랫폼마다
                  적합한 포맷은 다를까?

                  틱톡은 카드뉴스를 사진 슬라이드 형태로
                  업로드하고, 인스타그램과 유튜브는
                  영상형으로 변환해 운영했습니다.

                  결론

                  같은 원본 콘텐츠라도
                  플랫폼의 소비 방식에 따라
                  전달 방식이 달라져야 했습니다.

                  TEST 03

                  AI는 어디까지
                  운영에 활용할 수 있을까?

                  주제 리서치, 초안 구성, 블로그 글 확장,
                  성과 분석 보조에 AI를 활용했습니다.

                  결론

                  AI는 콘텐츠를 완성하는 도구보다
                  반복 작업을 줄이고 운영 속도를
                  높이는 도구에 가까웠습니다.
